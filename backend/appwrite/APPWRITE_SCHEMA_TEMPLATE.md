# Appwrite schema template validation

This is offline-only validation of the checked-in schema template. Run:

```sh
npm run validate:appwrite-template
```

It does not contact or modify Appwrite. It is not proof of Appwrite 1.9.6 compatibility and does not qualify live identity, pairing, mounted-device, household, permissions, transactions, or recovery behavior. Local HTTP 401 remained unresolved. No live qualification was completed.
